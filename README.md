# 光合作用 LLM Wiki

面向沒有生物學基礎的學習者，說明光能如何轉換為化學能。先討論主題與大綱，再將五篇教材資料摘要納入知識庫，依知識節點生成教學簡報。

## 重建
需 Python 3，執行 `python scripts/build.py` 與 `python scripts/check.py`。瀏覽器測試另見紀錄。網站不需要後端或 API 金鑰。

## GitHub Pages
將 ZIP 解壓後的內容（不是外層資料夾）上傳至公開 repository 根目錄，在 Settings → Pages → Deploy from a branch 選 main / (root)。首頁為 index.html。
